# Отчёт по компьютерной задаче «Спектральный анализ сетевого трафика для обнаружения аномалий»

**Вариант:** 01

---

## 1. Цель работы

Освоить дискретное преобразование Фурье (ДПФ) для анализа временного ряда сетевого трафика и научиться по амплитудному спектру находить аномальные частотные компоненты, а именно: признаки DDoS-атаки, ботнета, сканирования портов или скрытого канала.

## 2. Теоретическая часть

### 2.1. Спектральный анализ

Любой ряд из $N$ точек можно записать как сумму постоянной составляющей и гармоник — синусов и косинусов с частотами $k$ циклов за весь период наблюдения. Спектральный анализ находит, какие гармоники присутствуют в сигнале и насколько они сильны.

### 2.2. Формулы ДПФ

Для ряда $T(0), T(1), \dots, T(N-1)$:

$$\frac{a_0}{2} = \frac{1}{N}\sum_{j=0}^{N-1} T(j)$$

$$
a_k = \frac{2}{N}\sum_{j=0}^{N-1} T(j)\cos\left(\frac{2\pi k j}{N}\right), \qquad
b_k = \frac{2}{N}\sum_{j=0}^{N-1} T(j)\sin\left(\frac{2\pi k j}{N}\right)
$$

$$A_k = \sqrt{a_k^2 + b_k^2}$$

Формула для $a_k$ при $k = 0$ даёт $a_0 = \frac{2}{N}\sum T(j)$, поэтому в программе $a_0$ считается той же функцией, а среднее равно $a_0/2$.

### 2.3. Тригонометрический многочлен порядка K

$$T(t) \approx \frac{a_0}{2} + \sum_{k=1}^{K}\left(a_k\cos\frac{2\pi k t}{N} + b_k\sin\frac{2\pi k t}{N}\right)$$

### 2.4. Критерий аномалии

У нормального трафика есть большой пик на $k = 1$ (суточный цикл), возможно на $k = 2$ (утренний и вечерний пики), а на высоких $k$ амплитуды малы. Аномалия — это гармоника, амплитуда которой резко выделяется на фоне остальных.

Чтобы «резко выделяется» было не на глаз, в работе используется правило трёх сигм:

$$A_k > \overline{A} + 3\,\sigma_A,$$

где $\overline{A}$ и $\sigma_A$ — среднее и СКО амплитуд по $k = 1..50$.

Статистика амплитуд $k = 1..50$: среднее $\overline{A} = 2.43$, СКО $\sigma_A = 1.02$, порог $\overline{A} + 3\sigma_A = 5.48$.

Ни одна гармоника порог не превышает. Максимум ($k = 34$, $A = 4.86$) превышает среднее всего на 2.4σ. Сам спектр «плоский»: амплитуды равномерно разбросаны от ~1 до ~5 по всему диапазону $k$, без выраженных пиков.

Отдельно стоит отметить, что амплитуда на $k = 1$ (2.87) ничем не выделяется: суточного цикла в данных нет. Гармоника $k = 1$ составляет менее 10 % СКО ряда.

### Шаг 4. Анализ аномалий

**Есть ли в спектре аномальные пики?** Нет. По правилу трёх сигм ни одна гармоника $k = 1..50$ не выделяется.

**На каких k они находятся?** Аномальных $k$ нет. Наибольшие амплитуды у $k = 34$ и $k = 33$, но они в пределах случайного разброса.

**Проверка по модели белого шума.** Если ряд — независимый шум с СКО $\sigma \approx 29.4$, то каждый из $a_k$, $b_k$ — случайная величина с СКО $\sigma\sqrt{2/N} \approx 1.86$, а амплитуды $A_k$ распределены по закону Рэлея. Тогда:

| Величина                          |                          Теория для шума | Факт |
| --------------------------------- | ---------------------------------------: | ---: |
| Средняя амплитуда                 |          $1.86\sqrt{\pi/2} \approx 2.33$ | 2.43 |
| Ожидаемый максимум из 50 амплитуд | $\approx 1.86\sqrt{2\ln 50} \approx 5.2$ | 4.86 |

Фактические амплитуды совпадают с теми, что дал бы чистый шум. Значит, спектр полностью объясняется случайными колебаниями.

**Что это может означать?**

1. **Признаков DDoS, ботнета, сканирования портов или скрытого канала не обнаружено.** Каждая из этих атак дала бы узкий выраженный пик (ботнет или скрытый канал — на своей частоте опроса, сканирование — на частоте перебора) или резкий рост среднего уровня (DDoS). Ничего из этого в данных нет.
2. **Ожидаемой «нормальной» структуры тоже нет.** Методичка предполагает большой пик на $k = 1$ (суточный цикл), здесь его нет. Это может означать, что наблюдение охватывает слишком короткий интервал (500 секунд, около 8 минут) для проявления суточного цикла, или что источник сам по себе генерирует трафик без суточного ритма (например, фоновый межсерверный обмен). Также это может быть следствием того, что ряд — модельный и содержит только шум.

**Вывод по шагу 4:** трафик варианта 01 по спектру соответствует стационарному случайному процессу (белому шуму) вокруг 500 пакетов/с. Аномальных частотных компонент нет.

### Шаг 5. Тригонометрические многочлены

![Приближения K = 2 и K = 20](figures/approximation.png)

Качество приближения оценено по среднеквадратичной ошибке:

$$\text{RMSE} = \sqrt{\frac{1}{N}\sum_{t}\big(T(t) - \hat T(t)\big)^2}$$

| Модель                   |  RMSE | Объяснённая доля дисперсии |
| ------------------------ | ----: | -------------------------: |
| Только среднее ($a_0/2$) | 29.41 |                        0 % |
| K = 2                    | 29.30 |                      0.7 % |
| K = 20                   | 28.39 |                      6.8 % |

**Сравнение.**

- **K = 2** — почти прямая линия на уровне 500 с еле заметным изгибом. Она отражает средний уровень и подтверждает, что медленной (суточной) составляющей нет.
- **K = 20** — заметно «волнистая» кривая, которая повторяет часть случайных колебаний. Ошибка уменьшилась лишь с 29.41 до 28.39.

Для белого шума каждая пара коэффициентов $(a_k, b_k)$ «объясняет» в среднем $2/N$ дисперсии. Для 20 гармоник это $40/500 = 8\%$, что практически совпадает с полученными 6.8 %. То есть многочлен K = 20 подгоняется под шум, а не находит в данных новую закономерность (переобучение).

**Какой порядок лучше описывает данные?** Для этого ряда **K = 2** (и фактически даже одно среднее значение). K = 20 формально точнее на исходных точках, но выигрыш получен за счёт повторения случайных колебаний, а не реальной периодичности. Как модель «нормального» трафика, с которой можно сравнивать будущие наблюдения, лучше простой многочлен K = 2.

## 4. Выводы

1. Ряд варианта 01 — стационарный: среднее 500.2 пакетов/с, СКО 29.4. Тренда, периодичности и всплесков-атак нет.
2. Амплитудный спектр плоский. Ни одна гармоника не превышает порог $\overline{A} + 3\sigma_A = 5.48$. Наблюдаемые амплитуды совпадают с теоретическими значениями для белого шума.
3. Аномальных частотных компонент, указывающих на DDoS, ботнет, сканирование портов или скрытый канал, **не обнаружено**. Ожидаемого суточного пика на $k = 1$ тоже нет.
4. Из тригонометрических многочленов лучше подходит K = 2. K = 20 почти не уменьшает ошибку (на 3.5 %) и фактически аппроксимирует шум.
